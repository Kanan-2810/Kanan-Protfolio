# Kanan Dave — Portfolio (Next.js)

A single-page portfolio built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**. Professional dark theme with sky/cyan accents.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
npm start
```

## Structure

- **Hero** — Name, title, and primary CTA
- **Resume** — Education and experience timeline
- **About** — Bio, photo, and CV download
- **Expertise** — Frontend, AI, full-stack, tools
- **Services** — Frontend, backend API, Web3
- **Footer** — Social links (Instagram, LinkedIn)

Assets: `public/images/` (about photo), `public/pdf/` (resume PDF).
